# Console Calculator.js
Simplified calculator with popular math operations, __JavaScript only (NodeJS)__ .
## Features
* **__Recursion:__** In case of getting `NaN` function continuous to work.
* **__Operands validation:__** There is a check for `NaN` and division by zero.
* **__History of calculations:__** All your's results saves into array by short circuit.
## Requerments
1. __NodeJS:__ Make sure that [Node.js](https://nodejs.org/en) is installed.
2. __Clone repository into empty folder:__ ```git clone git@github.com:babachooga/Calculator.js.git```.
3. __Dependencies instalation:__ ```make install``` / ```npm ci```.
4. __Run code:__ ```calc```.
